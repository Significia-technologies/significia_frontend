# Significia RFinance Dashboard

A modern web interface dedicated to secure investor compliance reporting and Investment Advisor profile tracking.

## 🎯 Getting Started

First, install target client dependencies:

```bash
npm install
```

Then, fire up the development local server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) on your browser endpoint to verify.

## 🛠 Technical Stack

* **Core Frame**: Next.js 14 (App Router)
* **UI Foundations**: Tailwind CSS + Shadcn Primitives
* **API Pipeline**: Local Bridge Gateway Architecture
